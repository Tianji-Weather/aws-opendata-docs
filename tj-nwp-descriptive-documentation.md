# TJweather Global-Regional Integrated Numerical Weather Prediction System Dataset（SD3）

## Description

The TJweather Global-Regional Integrated Numerical Weather Prediction System Dataset provides high-resolution weather forecasts generated by a next-generation numerical weather prediction system developed by Tianji Weather based on the Super Dynamics on Cube (SD3) framework. The system integrates a cubed-sphere grid, non-hydrostatic dynamical core, heterogeneous computing architecture, and Global Free-Zoom technology, enabling seamless transition from ~12 km global forecasts to 5 km refined simulations over Asia without traditional nesting artifacts. TJweather provides forecasts extending up to 45 days, with reliable predictive skill reaching approximately 10 days, and demonstrates strong performance in complex terrain, extreme weather events, and subseasonal forecasting.

The dataset is distributed in **NetCDF4** format with standardized self-describing metadata and multidimensional gridded organization, supporting efficient access, interoperability, and scalable processing workflows. It provides high-resolution forecast outputs over Southeast Asia and Africa, including surface meteorological fields, multi-level atmospheric states, land-surface variables, environmental parameters, and application-oriented products. Key variables include precipitation, temperature, wind, humidity, radiation, dust concentration, and tropical cyclone track forecasts over the Western Pacific.

Combining long-range forecasting capability, flexible regional refinement, and rich scientific content, TJweather supports a wide range of applications, including weather forecasting, disaster mitigation, renewable energy, transportation, climate-risk assessment, and AI/ML research.
